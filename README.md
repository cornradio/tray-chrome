# TrayChrome - 托盘浏览器

## ✨ 主要特性

- 🎯 **托盘集成**：最小化到系统托盘，不占用任务栏空间
- 📱 **移动优先**：默认使用移动端 User-Agent，适合移动版网站
- 🎨 **超级极简模式**：隐藏工具栏，纯净浏览体验
- **Alt 拖动**：极简模式下按住 Alt 并左键拖动网页即可移动窗口，不会触发网页点击
- **App 组**：保存所有实例的 URL、图标和窗口尺寸，在设置或托盘右键菜单中切换多组 JSON 文件
- **窗口透明度**：支持 30%-100% 透明度，并可用复杂组合快捷键临时恢复不透明
- 🔄 **多实例支持**：可同时运行多个独立的浏览器实例
- 🌙 **暗色模式**：支持网页暗色模式切换
- 📌 **窗口置顶**：可设置窗口始终保持在最前面
- ⭐ **收藏夹管理**：本地收藏夹存储和管理
- 📢 **去广告功能**：简单的自定义去广告规则。


## 用法
双击启动，ctrl+中键开启新窗口，中键托盘图标退出。

托盘右键菜单使用竖向菜单项，包含增加实例、重启实例和关闭实例。

#### 快捷键说明

| 快捷键                     | 功能                         |
|---------------------------|------------------------------|
| `中键(tray icon)`                | 关闭 TrayChrome 实例          |
| `Ctrl + 中键(tray icon)`                | 关闭当前实例                  |
| `Ctrl + Shift + L`        | 聚焦到地址栏（极简模式会先显示工具栏） |
| `Ctrl + R`                | 刷新当前页面                  |
| `Ctrl +Shift + O`      | 书签                   |
| `Ctrl +Shift + B`                 | 切换极简模式（Clean 模式）  |
| `Ctrl + 点击链接` | 在新窗口中打开 |
| `Ctrl + Shift + 点击链接` | 用系统默认浏览器打开 HTTP/HTTPS 链接 |
| `Alt + 左键拖动` | 极简模式下移动窗口，不点击网页 |
| `Ctrl + Alt + Shift + T` | 当前窗口在设定透明度与完全不透明之间切换 |

透明度在「设置 → 外观设置」中调整；快捷键只临时切换当前窗口，不改写保存的透明度。置顶按钮使用固定的单色图形，蓝色表示置顶，灰色表示未置顶。

### 参数说明
```bash
.\TrayChrome.exe [参数]
```

| 参数 | 功能 | 示例 |
|------|------|------|
| `--url <网址>` | 指定启动时加载的网页 | `--url "https://www.google.com"` |
| `--open` | 启动时直接显示窗口 | `--open` |
| `--clean` | 启用超级极简模式（隐藏工具栏） | `--clean` |
| `--unclean` | 强制禁用超级极简模式 | `--unclean` |
| `--help` 或 `-h` | 显示帮助信息 | `--help` |
| `--size <宽度x高度>` | 指定窗口大小 | `--size 800x600` |
| `--icon <图标路径>` | 指定当前实例的 PNG/ICO 图标，不修改默认图标 | `--icon "C:\Icons\app.png"` |
| `--app-group <组文件路径>` | 打开组内全部 App，保留原有实例，不额外创建空白实例 | `--app-group "C:\Groups\work.json"` |

### 参数使用示例

```bash
# 启动极简模式jandan.net
.\TrayChrome.exe --url "https://jandan.net" --open --clean

# 强制禁用极简模式启动
.\TrayChrome.exe --unclean

# 显示帮助信息
.\TrayChrome.exe --help

# 直接打开网页并显示窗口
.\TrayChrome.exe --url "https://www.baidu.com" --open

```

## 📁 文件存储

应用程序数据存储在traychrome.exe同目录下，理论上是编写绿色软件。

但是其他电脑上不一定又dotnet环境。

### App 组

在「设置 → App 组」中：

- **把当前窗口保存成 App 组**：确认覆盖后将所选组替换为仅包含当前窗口的配置，不采集其他实例；没有配置时保存到 `apps.json`。
- **当前配置另存为**：复制所选组的全部条目到另一个 JSON 文件，不采集运行实例。
- **导入组文件**：将已有 JSON 文件加入组列表；下拉框切换当前管理的文件，不会立即关闭窗口。
- **配置列表**：只显示 JSON 文件名，悬停可查看完整路径。
- **图标预览与编辑**：每个 App 显示 Logo；点击 Logo 选择 PNG/ICO 即刻更新。点击「编辑」可修改 URL、更换图标，点击编辑窗口的「保存」后写入组文件，「取消」不修改配置。URL 仅支持 HTTP/HTTPS。新图标复制到程序目录的 `Resources/custom-icons`，不改变已运行实例的图标。
- **删除条目**：直接从所选组的 JSON 中删除该 App，不弹确认，不关闭已运行实例，也不删除图标文件。
- **单独启动**：点击行内「启动」仅启动该条目到托盘，保留其 URL、图标、尺寸和独立快捷键，不启动其他条目、不关闭已有实例。
- **实例独立快捷键**：在条目的「编辑」窗口中点击快捷键输入框，再直接按组合键录入，无需手打；支持 Ctrl/Alt/Shift/Win 加 A-Z、0-9、F1-F24。「清除」取消绑定。Tab 可切换焦点，Esc 可取消编辑。保存后下次启动此 App 生效，用于显示/隐藏对应实例。留空时不注册快捷键，也不继承共享快捷键。快捷键只保存在组条目中，不会改写共享设置。同组重复组合无法保存，系统或其他实例占用时启动会提示；不会抢占原绑定，窗口仍可通过托盘使用。重复启动同一条目或同一组也可能产生快捷键冲突。重启实例和保存实例快照会保留其独立绑定。
- **移除配置**：位于配置下拉框右侧，直接从列表移除并删除对应 JSON 文件，不弹确认。默认配置 `apps.json` 也可移除；移除全部配置后列表保持为空，可重新导入或保存当前窗口。已有实例不受影响，但引用被删配置的桌面快捷方式将失效。
- **在资源管理器中打开**：位于配置下拉框右侧，定位并选中对应 JSON 文件。
- **加载所选组**：额外启动组内全部 App，仅显示托盘图标，不弹出窗口，保留所有原有实例。可点击对应托盘图标或使用实例快捷键显示窗口。设置页、托盘菜单和桌面快捷方式的组启动行为一致；重复加载会再启动一组实例。普通重启实例仍会显示窗口。
- **加载组 & 关闭当前实例**：和绿色「加载组」一起放在页面顶部，成功打开组后仅退出当前实例；加载失败不关闭当前实例，其他实例不受影响。
- **创建桌面快捷方式**：为下拉框所选组创建桌面 `.lnk`，双击即可打开组内全部 App，保留现有实例，不额外创建空白窗口。重名快捷方式自动加数字后缀，不覆盖原文件。快捷方式引用组文件的绝对路径；组内容修改后会加载最新内容，移动或删除组文件后需重新创建快捷方式。

组文件先完整校验，再启动组内 App；普通加载不会关闭或修改原有窗口。如果加载失败，只回收本次新启动的实例。

`apps.json` 示例（可直接编辑；图标可以是本地 PNG/ICO 文件，相对路径以组文件目录为基准，留空则使用默认图标）：

```json
{
  "Name": "工作",
  "Apps": [
    {
      "Url": "https://example.com",
      "IconPath": "icons\\work.png",
      "Width": 480,
      "Height": 640,
      "IsSuperMinimalMode": true,
      "Hotkey": "Ctrl + Alt + 1"
    }
  ]
}
```

多组文件路径和最近选择保存在程序目录的 `app-groups.json`；导出组不包含登录状态、密码或网页会话。迁移自定义图标时需同时复制对应图标文件。

组内编辑、更换图标和删除条目会立即保存到当前组文件，与设置窗口底部的「应用」「保存并关闭」无关。
设置保存遇到空白、非数字或越界的窗口尺寸时，会恢复默认宽高（360x640）并记录日志，不再阻止保存。
主窗口最小尺寸为 200x150。启动时自动修复历史配置中的异常尺寸；最小化时保存正常窗口的恢复尺寸，避免将极小的最小化尺寸写入配置。设置中的宽高应用后立即生效。
保存当前窗口到 App 组同样使用正常窗口尺寸；组文件中的异常宽高在读取时恢复默认值，显示托盘窗口前先退出最小化状态并恢复尺寸。
托盘右键「恢复默认大小和位置」可恢复 360x640，并将窗口放回当前屏幕右下角、显示窗口并保存。

### 自定义图标

「设置 → 外观设置 → 图标设置」提供独立的「自定义」单选项。选择文件默认筛选 PNG，其次为 ICO；点击「应用」或「保存并关闭」后生效。选择无效、损坏或超过 5MB 的图标会提示错误。重启后保留自定义选择，不会再被默认图标覆盖。

也可在托盘右键菜单点击「自定义图标...」，选取 PNG/ICO 后立即更新当前实例的托盘和窗口图标，并保存为默认图标设置，无需打开设置窗口；其他已运行实例的图标不变。

裁剪功能暂时停用以排查自定义图标闪退。托盘、外观设置和 App 组选择 PNG/ICO 后均直接导入原图，不再打开裁剪窗口；裁剪代码保留但入口不参与编译。


## 🛠️ 技术栈

- **框架**：.NET 9.0 + WPF
- **浏览器引擎**：Microsoft WebView2
- **托盘支持**：Hardcodet.NotifyIcon.Wpf
- **目标平台**：Windows 10/11

网页使用 WebView2CompositionControl，以便窗口透明度、圆角裁剪和 Alt 拖动同样作用于网页区域；需要已安装 WebView2 Runtime。
项目须使用 `net9.0-windows10.0.17763.0` 目标框架，以自动包含组合控件需要的 Windows SDK .NET 运行时程序集；仅使用 `net9.0-windows` 会导致首次显示窗口时缺少程序集。


## FAQ

### 点击托盘后闪退，在哪里查看日志？

程序按进程写入日志到 `%LOCALAPPDATA%\TrayChrome\logs`，文件名格式为 `TrayChrome-日期-进程ID.log`。日志包含启动、托盘点击、窗口显示/隐藏、WebView2 初始化失败和未处理异常的堆栈。文件中可能包含本机路径或异常上下文，分享前请检查敏感内容。

```powershell
explorer.exe "$env:LOCALAPPDATA\TrayChrome\logs"
```

如果进程被系统或原生组件直接终止，托管异常日志不一定有堆栈；可在 Windows 事件查看器的「Windows 日志 → 应用程序」中查看对应的 `.NET Runtime` / `Application Error` 记录。

### 打包提示 No .NET SDKs were found

打包需要 **.NET 9 SDK**，仅安装 .NET Desktop Runtime 只能运行程序，不能编译。请从 https://dotnet.microsoft.com/download/dotnet/9.0 安装 Windows x64 SDK，然后运行：

```powershell
.\pack.ps1
```

脚本会检查 PATH、`DOTNET_ROOT`、用户目录的 `.dotnet` 和 Program Files 中的 SDK。自定义安装位置可以显式指定：

```powershell
.\pack.ps1 -DotnetPath 'C:\Tools\dotnet\dotnet.exe' -NoPrompt
```

输出固定在项目目录下的 `publish`，与执行命令时所在目录无关。目标机器仍需 .NET 9 Desktop Runtime 和 WebView2 Runtime。

如何配置代理：https://github.com/cornradio/tray-chrome/issues/15#issuecomment-3798148987
