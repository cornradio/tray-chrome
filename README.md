# TrayChrome - 托盘浏览器

一个基于 WPF 和 WebView2 的轻量级托盘浏览器，专为 Windows 设计。类似 MenubarX，但更加轻便和功能丰富。

## ✨ 主要特性

- 🎯 **托盘集成**：最小化到系统托盘，不占用任务栏空间
- 📱 **移动优先**：默认使用移动端 User-Agent，适合移动版网站
- 🎨 **超级极简模式**：隐藏工具栏，纯净浏览体验
- **Alt 拖动**：极简模式下按住 Alt 并左键拖动网页即可移动窗口，不会触发网页点击
- **App 组**：保存所有实例的 URL、图标和窗口尺寸，在设置或托盘右键菜单中切换多组 JSON 文件
- 🔄 **多实例支持**：可同时运行多个独立的浏览器实例
- **实例内多标签页**：同一窗口内新增、切换和关闭网页，共用一个托盘图标和实例快捷键。
- 🌙 **暗色模式**：支持网页暗色模式切换
- 📌 **窗口置顶**：可设置窗口始终保持在最前面
- ⭐ **收藏夹管理**：本地收藏夹存储和管理
- 📢 **去广告功能**：简单的自定义去广告规则。


## 用法
双击启动，ctrl+中键开启新窗口，中键托盘图标退出。

托盘右键菜单使用竖向菜单项，包含增加实例、重启实例和关闭实例。

#### 快捷键说明

| 快捷键                     | 功能                         |
|---------------------------|------------------------------|
| `中键(tray icon)`                | 关闭 TrayChrome 实例          |
| `Ctrl + 中键(tray icon)`                | 关闭当前实例                  |
| `Ctrl + Shift + L`        | 聚焦到地址栏（极简模式会先显示工具栏） |
| `Ctrl + R`                | 刷新当前页面                  |
| `Ctrl +Shift + O`      | 书签                   |
| `Ctrl +Shift + B`                 | 切换极简模式（Clean 模式）  |
| `Ctrl + 点击链接` | 在当前实例的新标签页打开 |
| `Ctrl + T` | 新建标签页 |
| `Ctrl + W` | 关闭当前标签页；只剩一页时隐藏窗口到托盘 |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | 切换到下一页 / 上一页 |
| `Ctrl + Shift + 点击链接` | 用系统默认浏览器打开 HTTP/HTTPS 链接 |
| `Alt + 左键拖动` | 极简模式下移动窗口，不点击网页 |

置顶按钮使用固定的单色图形，蓝色表示置顶，灰色表示未置顶。

标签栏仅在有多个标签页且非极简模式时显示，只有一页时自动隐藏，按 Ctrl+T 新增后展开。`+` 只显示在展开的标签栏内，窗口关闭按钮旁不再显示。标签采用无边框纯文本，以 `|` 分隔；底色与上方工具栏一致，当前页仅通过字重和文字明暗区分，不使用反色块、亮边框或蓝色高亮。中键点击标签关闭，右键可关闭当前页、其他页、右侧页或刷新，不显示单独的关闭按钮。每页保留各自的网页、导航历史和滚动状态；地址栏与导航按钮操作当前页。缩放、UA、广告规则、窗口尺寸和实例快捷键为实例级设置。极简模式隐藏标签栏，但仍可使用上述快捷键；Ctrl+Shift+L 可退出极简模式并聚焦地址栏。普通弹出链接保持在当前页打开，Ctrl+Shift+点击仍使用系统默认浏览器。

### 参数说明
```bash
.\TrayChrome.exe [参数]
```

| 参数 | 功能 | 示例 |
|------|------|------|
| `--url <网址>` | 指定启动时加载的网页 | `--url "https://www.google.com"` |
| `--tab <网址>` | 在同一实例中追加标签页，可重复指定 | `--tab "https://example.com"` |
| `--open` | 启动时直接显示窗口 | `--open` |
| `--clean` | 启用超级极简模式（隐藏工具栏） | `--clean` |
| `--unclean` | 强制禁用超级极简模式 | `--unclean` |
| `--help` 或 `-h` | 显示帮助信息 | `--help` |
| `--size <宽度x高度>` | 指定窗口大小 | `--size 800x600` |
| `--icon <图标路径>` | 指定当前实例的 PNG/ICO 图标，不修改默认图标 | `--icon "C:\Icons\app.png"` |
| `--app-group <组文件路径>` | 打开组内全部 App，保留原有实例，不额外创建空白实例 | `--app-group "C:\Groups\work.json"` |

### 参数使用示例

```bash
# 启动极简模式jandan.net
.\TrayChrome.exe --url "https://jandan.net" --open --clean

# 强制禁用极简模式启动
.\TrayChrome.exe --unclean

# 显示帮助信息
.\TrayChrome.exe --help

# 直接打开网页并显示窗口
.\TrayChrome.exe --url "https://www.baidu.com" --open

```

### 收藏夹功能

独立书签管理器在目录树右上角提供「全部折叠」，会收起全部文件夹及子文件夹。顶部目录下拉框用于定位：选择后展开路径、选中并滚动到目标文件夹，选择「全部书签」回到树顶部。树中选中书签按 Enter 在浏览器当前页打开，选中文件夹按 Enter 展开并定位；Del 或右键删除不再确认。新增、编辑、移动（包括拖拽）、删除及导入后保留折叠状态、仍存在的选中项、滚动位置和当前筛选。

通过 Enter、双击或右键打开书签 URL 后，浏览器会恢复显示并激活到前方、聚焦网页；已经显示的窗口也会激活，不改变置顶设置。打开文件夹只在管理器内定位。

搜索框同时筛选名称与 URL，不区分大小写；输入时不刷新树，点击「搜索」或在搜索框按 Enter 才执行。保留匹配项的祖先文件夹并展开路径；清空输入后再执行搜索恢复完整树，不修改存储数据。搜索时的导出仍导出全部书签；通过目录下拉框定位会清空并取消搜索，避免目标被筛选隐藏。

- 书签菜单、书签右键编辑菜单与标签右键菜单采用同一套紧凑样式，背景、文字和分隔线跟随窗口主题，不显示默认的图标侧栏；切换主题后下次打开立即使用新配色。
- **添加收藏**：浏览器小菜单的「添加到收藏夹」保存当前页面；书签管理器的「添加收藏」打开空白编辑窗口，自行填写标题和 HTTP/HTTPS URL，确认后保存到当前目录。
- **管理收藏**：从星形按钮菜单、托盘「书签管理器」或「设置 → 收藏夹 → 打开书签管理器」进入独立非模态窗口；每个实例只打开一个管理器，重复打开会激活已有窗口并恢复最小化状态。管理器不依附浏览器置顶，管理、编辑或移动书签时仍可使用浏览器。编辑/移动窗口同一时间只开一个，期间仅禁用管理器自身；关闭后恢复。浏览器/托盘更新书签时会关闭未保存的编辑窗口并刷新管理器，避免保存过期条目。树中只显示标题与 URL，不显示行内按钮；右键所在项会先选中，菜单提供打开、编辑、移动和删除。「打开」会在当前标签页导航，文件夹则展开；树获得焦点时可按 Del 删除选中项，不弹确认，保存失败会恢复该项。「打开配置文件」仅位于管理器，星形按钮菜单不再提供 JSON 编辑入口。
- **树状文件夹管理**：树中展开/折叠文件夹，逐行编辑、移动和删除。拖动书签或文件夹到目标文件夹中即可移入，放在普通书签上则移入该书签所属目录，放在树的空白处移回根目录；拖拽不会改变同一目录内顺序。按钮点击不会触发拖拽，不允许移入自身或后代。选中文件夹或使用上方下拉框确定新增/导入目录。删除文件夹会直接连同内容删除，不弹确认。
- **导入浏览器书签**：从「导入 / 导出 → 导入浏览器书签」进入。先在 Chrome、Edge、Firefox 等浏览器中导出 HTML，再导入。保留嵌套文件夹并合并到当前目录，不覆盖已有收藏；重复导入会追加。不支持的地址（如 `chrome://`、`javascript:`）及无效地址会跳过，完成后汇总导入和跳过数量，不影响有效条目。文件读取或格式错误仍会提示。
- **导出到 Chrome**：点击「导入 / 导出 → 导出 HTML」导出整个书签树（不是仅选中的文件夹），在 Chrome 的书签管理器中通过「导入书签」读取此文件；保留中文、文件夹及 URL。
- **配置格式**：窗口、托盘和管理器统一使用程序目录中的 `Bookmarks.chrome.json`，采用 Chrome Bookmarks 的 `version` / `roots` / `type` / `name` / `url` / `children` 结构。旧 `bookmarks.json` 保留但不自动迁移或继续读取；这是 TrayChrome 自己的文件，不会改写本机 Chrome 配置。与浏览器交换书签请使用 HTML 导入/导出，不要运行中直接覆盖 Chrome 的内部文件。
- **快速访问**：收藏夹菜单中直接点击网站名称


## 📁 文件存储

应用程序数据存储在traychrome.exe同目录下，理论上是编写绿色软件。

但是其他电脑上不一定又dotnet环境。

### App 组

在「设置 → App 组」中：

- **把所有已开 App 保存成组**：确认覆盖后采集同一路径程序的全部运行实例，包括隐藏到托盘的实例，保存各自 URL、图标、正常窗口尺寸和快捷键并替换所选组；没有配置时保存到 `apps.json`。任一实例无法读取时提示错误，不覆盖原配置，也不保存残缺组。
- **多标签页保存**：JSON 中每个实例仍对应一个条目，`Url` 保存当前页，`Tabs` 保存其他页 URL；设置列表将全部 URL 展开为一行一个，并显示「所属实例」。同一实例的各行加载时恢复到同一个多 Tab 窗口，行内「启动」也会启动该实例的全部页面。每行可独立编辑 URL 或删除页面，删除最后一页才移除实例；图标和快捷键为所属实例共享。加载组、单独启动和重启会恢复全部页面，保存时的当前页作为第一标签打开；旧配置没有 `Tabs` 时仍按单页启动。仅保存 URL，不保存页面会话或滚动状态。
- **当前配置另存为**：复制所选组的全部条目到另一个 JSON 文件，不采集运行实例。
- **导入组文件**：将已有 JSON 文件加入组列表；下拉框切换当前管理的文件，不会立即关闭窗口。
- **配置列表**：只显示 JSON 文件名，悬停可查看完整路径。
- **图标预览与编辑**：每个 App 显示 Logo；点击 Logo 选择 PNG/ICO 即刻更新。点击「编辑」可修改 URL、更换图标，点击编辑窗口的「保存」后写入组文件，「取消」不修改配置。URL 仅支持 HTTP/HTTPS。新图标复制到程序目录的 `Resources/custom-icons`，不改变已运行实例的图标。
- **删除条目**：直接从所选组的 JSON 中删除该 App，不弹确认，不关闭已运行实例，也不删除图标文件。
- **单独启动**：点击行内「启动」仅启动该条目到托盘，保留其 URL、图标、尺寸和独立快捷键，不启动其他条目、不关闭已有实例。
- **实例独立快捷键**：在条目的「编辑」窗口中点击快捷键输入框，再直接按组合键录入，无需手打；支持 Ctrl/Alt/Shift/Win 加 A-Z、0-9、F1-F24。「清除」取消绑定。Tab 可切换焦点，Esc 可取消编辑。保存后下次启动此 App 生效，用于显示/隐藏对应实例。留空时不注册快捷键，也不继承共享快捷键。快捷键只保存在组条目中，不会改写共享设置。同组重复组合无法保存；系统或其他实例占用时跳过当前实例的绑定，仅记日志、不弹窗，也不会抢占原绑定，窗口仍可通过托盘使用。共享快捷键遇到占用时同样处理，其他注册错误仍会提示。重复启动同一条目或同一组也可能产生快捷键冲突。重启实例和保存实例快照会保留其独立绑定。
- **移除配置**：位于配置下拉框右侧，直接从列表移除并删除对应 JSON 文件，不弹确认。默认配置 `apps.json` 也可移除；移除全部配置后列表保持为空，可重新导入或保存当前窗口。已有实例不受影响，但引用被删配置的桌面快捷方式将失效。
- **在资源管理器中打开**：位于配置下拉框右侧，定位并选中对应 JSON 文件。
- **加载所选组**：额外启动组内全部 App，仅显示托盘图标，不弹出窗口，保留所有原有实例。可点击对应托盘图标或使用实例快捷键显示窗口。设置页、托盘菜单和桌面快捷方式的组启动行为一致；重复加载会再启动一组实例。普通重启实例仍会显示窗口。
- **加载组 & 关闭当前实例**：和绿色「加载组」一起放在页面顶部，成功打开组后仅退出当前实例；加载失败不关闭当前实例，其他实例不受影响。
- **创建桌面快捷方式**：为下拉框所选组创建桌面 `.lnk`，双击即可打开组内全部 App，保留现有实例，不额外创建空白窗口。重名快捷方式自动加数字后缀，不覆盖原文件。快捷方式引用组文件的绝对路径；组内容修改后会加载最新内容，移动或删除组文件后需重新创建快捷方式。

组文件先完整校验，再启动组内 App；普通加载不会关闭或修改原有窗口。如果加载失败，只回收本次新启动的实例。

`apps.json` 示例（可直接编辑；图标可以是本地 PNG/ICO 文件，相对路径以组文件目录为基准，留空则使用默认图标）：

```json
{
  "Name": "工作",
  "Apps": [
    {
      "Url": "https://example.com",
      "IconPath": "icons\\work.png",
      "Width": 480,
      "Height": 640,
      "IsSuperMinimalMode": true,
      "Hotkey": "Ctrl + Alt + 1"
    }
  ]
}
```

多组文件路径和最近选择保存在程序目录的 `app-groups.json`；导出组不包含登录状态、密码或网页会话。迁移自定义图标时需同时复制对应图标文件。

组内编辑、更换图标和删除条目会立即保存到当前组文件，与设置窗口底部的「应用」「保存并关闭」无关。
设置保存遇到空白、非数字或越界的窗口尺寸时，会恢复默认宽高（360x640）并记录日志，不再阻止保存。
主窗口最小尺寸为 200x150。启动时自动修复历史配置中的异常尺寸；最小化时保存正常窗口的恢复尺寸，避免将极小的最小化尺寸写入配置。设置中的宽高应用后立即生效。
保存当前窗口到 App 组同样使用正常窗口尺寸；组文件中的异常宽高在读取时恢复默认值，显示托盘窗口前先退出最小化状态并恢复尺寸。
托盘右键「恢复默认大小和位置」可恢复 360x640，并将窗口放回当前屏幕右下角、显示窗口并保存。

### 自定义图标

「设置 → 外观设置 → 图标设置」提供独立的「自定义」单选项。选择文件默认筛选 PNG，其次为 ICO；点击「应用」或「保存并关闭」后生效。选择无效、损坏或超过 5MB 的图标会提示错误。重启后保留自定义选择，不会再被默认图标覆盖。

也可在托盘右键菜单点击「自定义图标...」，选取 PNG/ICO 后立即更新当前实例的托盘和窗口图标，并保存为默认图标设置，无需打开设置窗口；其他已运行实例的图标不变。

裁剪功能暂时停用以排查自定义图标闪退。托盘、外观设置和 App 组选择 PNG/ICO 后均直接导入原图，不再打开裁剪窗口；裁剪代码保留但入口不参与编译。


## 🛠️ 技术栈

- **框架**：.NET 9.0 + WPF
- **浏览器引擎**：Microsoft WebView2
- **托盘支持**：Hardcodet.NotifyIcon.Wpf
- **目标平台**：Windows 10/11

网页使用标准 WebView2 控件，需要已安装 WebView2 Runtime。项目使用 `net9.0-windows`，不再引入组合控件所需的大型 Windows SDK .NET 程序集。
窗口透明度及其快捷键已移除，旧配置中的透明度字段会被忽略。Alt 拖动通过网页输入桥接，使用系统实时按键状态和原生窗口移动操作，不依赖 WPF 的鼠标状态；仅在极简模式下生效。网页聚焦时的窗口快捷键通过 WebView2 键盘事件处理。圆角通过 WPF 内容裁剪与标准 WebView2 的原生窗口区域裁剪共同实现，极简模式下同样生效，并跟随尺寸、标签页和 DPI 更新，不引入大型 Windows SDK .NET 依赖。


## FAQ

### 点击托盘后闪退，在哪里查看日志？

程序按进程写入日志到 `%LOCALAPPDATA%\TrayChrome\logs`，文件名格式为 `TrayChrome-日期-进程ID.log`。日志包含启动、托盘点击、窗口显示/隐藏、WebView2 初始化失败和未处理异常的堆栈。文件中可能包含本机路径或异常上下文，分享前请检查敏感内容。

```powershell
explorer.exe "$env:LOCALAPPDATA\TrayChrome\logs"
```

如果进程被系统或原生组件直接终止，托管异常日志不一定有堆栈；可在 Windows 事件查看器的「Windows 日志 → 应用程序」中查看对应的 `.NET Runtime` / `Application Error` 记录。

### 打包提示 No .NET SDKs were found

打包需要 **.NET 9 SDK**，仅安装 .NET Desktop Runtime 只能运行程序，不能编译。请从 https://dotnet.microsoft.com/download/dotnet/9.0 安装 Windows x64 SDK，然后运行：

```powershell
.\pack.ps1
```

脚本会检查 PATH、`DOTNET_ROOT`、用户目录的 `.dotnet` 和 Program Files 中的 SDK。自定义安装位置可以显式指定：

```powershell
.\pack.ps1 -DotnetPath 'C:\Tools\dotnet\dotnet.exe' -NoPrompt
```

默认会生成两种 Windows x64 单文件版本，输出位置与执行命令时所在目录无关；可用 `-Edition framework-dependent` 或 `-Edition self-contained` 仅生成指定版本：

| 版本 | 可执行文件 | 目标机器的 .NET 要求 |
|------|------------|---------------------|
| 精简版 | `publish\framework-dependent\TrayChrome.exe` | 安装 .NET 9 Desktop Runtime（x64） |
| 独立版 | `publish\self-contained\TrayChrome.exe` | 自带运行时，无需安装 .NET，文件更大 |

两种版本**运行时都不需要 SDK**，但都需要安装 **WebView2 Runtime**；独立版不包含浏览器运行时。两种版本的打包过程都需要 SDK。
仅独立版启用单文件压缩，启动时解压程序集会增加少量开销。.NET 9 不支持精简版单文件压缩（启用会报 NETSDK1176），因此精简版显式关闭压缩。已移除透明度及其大型 Windows SDK .NET 依赖以减小体积；不启用程序集裁剪，以免破坏 WPF 或运行时功能。
脚本遇到任一版本发布失败时会报错并返回非零退出码。旧的 `publish\TrayChrome.exe` 和配置不会被删除或更新，请使用上述子目录里的新版；迁移已有设置、App 组和自定义图标时，请将相关 JSON 文件和图标资源一并复制到所选版本目录。

只打包精简版并复制到固定目录 `C:\AAA\Traychrome`：

```powershell
.\pack1.ps1
# 自定义 SDK 路径（可选）
.\pack1.ps1 -DotnetPath 'C:\Tools\dotnet\dotnet.exe'
```

此脚本复用 `pack.ps1`，不生成独立版、不弹出目录询问；仅覆盖目标目录的 `TrayChrome.exe`，保留配置、App 组和图标。打包失败时不会复制旧产物；复制失败会报错并返回非零退出码，不自动关闭运行中的实例。若 EXE 被占用，请自行退出对应实例后重试。
